# Готовая сборка

Из каталога `www`:

```sh
npm run build
```

Сборка использует сцену `div.html`. Результат находится в `dist`:

- `index.html` — стартовая страница;
- `assets/pyramid.js` — весь JavaScript приложения и библиотек в одном файле;
- `assets/*.css` — стили;
- картинки и GLB-модель — отдельные ресурсы в `assets`.

Для публикации скопируйте **содержимое `dist` целиком** на статический хостинг.
Исходники, `node_modules` и сервер Vite на хостинге не нужны.
Относительные пути позволяют разместить сборку в подпапке сайта.
Открывайте страницу через HTTP/HTTPS, а не через `file://`.

Локальная проверка готовой сборки:

```sh
npm run preview
```
