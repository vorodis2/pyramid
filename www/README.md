# Пирамидка v0.1

Прототип физической сцены: TypeScript, Vite, Three.js, OimoPhysics и React.

Физика работает на OimoPhysics 1.2.5 из официального репозитория `saharan/OimoPhysics`.
Модуль `src/physics/PhysicsWorld.js` связывает движок с блоками, удалением тел и перетаскиванием через сферический joint.
Для `type: 'model'` по умолчанию создаётся одна выпуклая оболочка всей модели. Параметр формы `parts`, например `{ type: 'model', size: [1, 1, 1], parts: 5 }`, включает адаптивное разбиение максимум на указанное число выпуклых частей. Разрезы выбираются по уменьшению лишнего объёма оболочки; части образуют одно физическое тело. Это приближение формы, а не точный треугольный коллайдер.

Параметр `primitiveParts`, например `{ type: 'model', size: [1, 1, 1], primitiveParts: 10 }`, вместо выпуклых мешей создаёт до указанного количества простых физических боксов. Разбиение подбирается по уменьшению пустого объёма боксов. Если заданы оба параметра, `primitiveParts` имеет приоритет над `parts`.

## Запуск

```bash
npm install
npm run dev
```

Требуется Node.js, совместимый с Vite 7 (20.19+ или 22.12+).

Клавиша **R** пересоздаёт физический мир, пирамиду и шар. Камера управляется мышью через OrbitControls.

Пирамида состоит из четырёх рядов (10 блоков) и имеет глубину в один куб. Два слайдера React-меню пока изменяют только состояние интерфейса.

## Архитектура

- `Glaf` — сцена, камера, рендеринг и физический мир с шагом 1/60 секунды.
- `Piramidka` — построение и очистка пирамиды.
- `Block` — контейнер Three.js, примитивы и физическое тело блока.
- `Menu` — React-интерфейс.

Для освобождения ресурсов приложения предусмотрен `Glaf.destroy()`, для удаления блока — `Block.delete()`.
